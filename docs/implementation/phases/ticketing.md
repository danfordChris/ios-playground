# Ticketing Phase

## Objective

Bring the ticketing workspace into contract-shaped documentation and keep the
existing mobile view aligned with that truth.

## Scope

- In scope: searchable ticket feed, create-ticket flow, ticket detail sheet,
  ticket-related mock data, and documentation that describes them.
- Out of scope: auth changes, backend integration, generated files, and other
  feature modules.

## Features

- Ticket list
- Ticket detail sheet
- Create ticket flow
